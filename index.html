CV Enhancer

Upload your CV and tell Gemini how to sharpen it. A GitHub Actions pipeline rewrites it and attaches the result as a downloadable artifact.

📎
Drag & drop or click to upload
.pdf · .docx · .txt — max 5 MB

How it works

1Your file is base64-encoded in the browser.
2A repository_dispatch event triggers GitHub Actions.
3Gemini (via LLM_API_KEY) rewrites the CV.
4The enhanced CV is saved as a run artifact & emailed to you.
Heads up: the dispatch token is handled by a serverless proxy, never exposed in the browser. Configure the endpoint in js/cv-enhancer.js.
